# 💰 Student Budget Tracker

A responsive personal finance web application built with HTML, CSS, and JavaScript.

The Student Budget Tracker allows users to record income and expenses, organize transactions by category, monitor their balance, and visualize spending.

## 🚀 Live Demo

https://maybeshankar.github.io/my-portfolio/expense-tracker/

## ✨ Features

- Add income and expenses
- Calculate current balance automatically
- Categorize transactions
- Edit transactions
- Delete individual transactions
- Clear all transactions
- Automatically record transaction dates
- Show spending breakdown by category
- Display newest transactions first
- Input validation
- Save transactions using browser LocalStorage
- Responsive user interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git & GitHub

## 📊 How It Works

Transactions are stored as JavaScript objects and saved in the browser using LocalStorage.

The application calculates:

**Balance = Income − Expenses**

The Spending Overview groups expenses by category and calculates the percentage of total spending for each category.

## 🧪 Example

A user can add:

| Description   | Amount | Type    | Category  |
| ------------- | -----: | ------- | --------- |
| Scholarship   | ₹5,000 | Income  | Other     |
| College Books |   ₹700 | Expense | Education |
| Lunch         |   ₹300 | Expense | Food      |

The application automatically calculates the remaining balance and updates the spending overview.
