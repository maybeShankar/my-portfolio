# 📚 StudyFlow

StudyFlow is a student productivity and study management dashboard built using **HTML, CSS, and JavaScript**.

It helps students organize their subjects, assignments, study sessions, notes, goals, and productivity in one place.

## Features

## ✨ Features

### 📖 Subject Management

- Add and remove subjects
- Organize study activities by subject

### 📝 Assignments & Tasks

- Create tasks
- Set subject, priority, and deadline
- Mark tasks as completed
- Filter tasks by All, Active, and Completed

### ⏱️ Study Timer

- Pomodoro — 25 minutes
- Deep Focus — 45 minutes
- Study Session — 60 minutes
- Deep Work — 90 minutes
- Custom study subject selection
- Start, pause, resume, and reset controls

### 👁️ Focus Monitor

- Webcam-based focus monitoring
- Face detection
- Eye-warning detection
- Face-lost detection
- Focus score tracking
- Study-session focus statistics

### 📊 Study Analytics

- Study history
- Weekly study analytics
- Subject performance
- Productivity trends
- Focus score tracking

### 🔥 Study Streak

- Current study streak
- Best streak
- Consistency tracking
- Missed study day detection

### 🎯 Daily Study Goal

- Set a daily study target
- Track progress toward the goal
- Goal completion notifications

### 🧠 Smart Study Features

- Smart study recommendations
- Smart daily planning
- Exam and deadline mode
- Subject performance analysis
- Smart streak and consistency
- Advanced dashboard

### 📅 Study Planner & Calendar

- Create study plans
- Set topic, subject, date, time, duration, and priority
- View upcoming plans
- Monthly study calendar
- Mark plans as completed

### 🏆 Achievements

- Track productivity achievements
- Unlock achievements through study activity

### 🔔 Notifications

- Browser study-session notifications
- Daily goal notifications
- Study completion alerts

### 📝 Notes

- Quick study notes
- Automatic saving using browser storage

### ⚙️ Settings

- Focus Monitor settings
- Notification settings
- Study settings
- Data and backup options
- Reset options
- Light/Dark theme

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
- MediaDevices API
- MediaPipe Face Landmarker
- Browser Notifications API

## 💾 Data Storage

StudyFlow uses **LocalStorage** to save user data directly in the browser.

This includes:

- Subjects
- Tasks
- Study history
- Study plans
- Notes
- Streak data
- Daily goals
- Settings
- Achievements

No external database is required for the basic application.

## 🚀 How to Run

1. Download or clone the repository.
2. Open the `studyflow` folder.
3. Open `index.html` in a browser.

For the best experience, run the project using a local development server such as **VS Code Live Server**.
